# Exploratory Data Analysis and Financial Performance Prediction of Infosys Ltd.

This repository contains an academic mini-project focused on exploring the financial performance of Infosys Ltd.

## Project Structure
- `data/`: Contains raw datasets (`raw/`) and processed, cleaned datasets (`processed/`).
- `scripts/`: Executable Python scripts running Data Cleaning, EDA, Statistical Analysis, and Regression.
- `src/`: Reusable Python modules for data cleaning, EDA, statistics, and regression.
- `visualizations/`: Generated visualizations categorized by metric.
- `reports/`: Final reports, dashboards, and figures.
- `presentation/`: PowerPoint or presentation files.

## Setup
Install dependencies using:
```bash
pip install -r requirements.txt
```
